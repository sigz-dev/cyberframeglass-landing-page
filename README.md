# Cyber Frameless Glass Installations — Landing Page

A single-page marketing site for **Cyber Frameless Glass Installations**, a glass, aluminium, and welding business based in Chitungwiza, Zimbabwe.

**Live site:** https://sigz-dev.github.io/cyberframeglass-landing-page/

## Overview

The page showcases the business's services and recent work, including:

- Frameless glass showers and balustrades
- Aluminium windows and sliding/stacking doors
- Glass balcony enclosures and display cabinets
- Arch welding, carpentry, and renovations

It's built for fast loading and good local SEO (structured data, Open Graph/Twitter meta tags, geo targeting for Chitungwiza, Zimbabwe) and includes a WhatsApp click-to-chat link for direct customer inquiries.

## Tech stack

- Plain HTML
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- No build step — open `index.html` directly or serve it statically

## Project structure

```
index.html        Single-page site (markup, content, styling config)
images/            Project photos used across the page
```

## Running locally

No build tools required. Either:

- Open `index.html` directly in a browser, or
- Serve the folder with any static file server, e.g.:
  ```sh
  npx serve .
  ```

## Deployment

The site is deployed via GitHub Pages from this repository.
