Drop your project photos into this folder using these exact file names
so they appear automatically on the landing page:

  hero-glass-door.jpg   -> big hero image (the frameless glass pivot door looks great here)
  about-work.jpg        -> the "About" section photo
  gallery-1.jpg         -> gallery photo 1
  gallery-2.jpg         -> gallery photo 2
  gallery-3.jpg         -> gallery photo 3

Tips:
- Keep them roughly the same orientation as the placeholder (hero = tall/portrait, gallery = square).
- JPG or PNG both work; if you use PNG just keep the .jpg name OR update the
  filename inside index.html.
- If an image is missing, the page falls back to a clean green block (no broken icon).
